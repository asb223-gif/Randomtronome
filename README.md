# Randomtronome v5

v3의 정상 작동하는 오디오/불빛 리듬 UI를 유지하면서 실제 악보 패널을 별도로 추가했습니다.

## 화면
1. SCORE — VexFlow 실제 악보
2. RANDOM RHYTHM — 기존 불빛/동그라미 표시
3. 설정
4. 하단 PLAY / STOP 단일 버튼

## 악보
- 4/4
- 16분음표 / 16분쉼표
- 3연음 / 3연음 내부 쉼표
- 16분음표 빔
- 3연음 숫자 표시
- 한 마디 안에서 16분과 3연음 혼합

악보 렌더링과 오디오 엔진은 분리되어 있어 VexFlow에 문제가 생겨도 재생은 계속 작동합니다.
