# Randomtronome v9

UI/악보 개선:
- SCORE / '생성된 리듬의 실제 악보' 텍스트 제거
- 악보를 더 크게 표시
- 음표 머리를 더 둥글고 크게 개선
- 16분쉼표 / 8분쉼표 SVG 모양 개선
- 연속된 16분쉼표 2개는 악보에서 8분쉼표 1개로 묶어 표시
- 박별 음 개수는 기본적으로 접혀 있고 탭하면 펼쳐짐
- BPM 컨트롤을 중앙의 `− 90 +` 형태로 변경
- BPM 영역을 오른쪽으로 스와이프하면 증가, 왼쪽으로 스와이프하면 감소
- 기존 랜덤 엔진, 불빛 표시, PLAY/STOP 즉시 정지는 유지
