# Randomtronome v10

- 악보 아래의 작은 1/2/3/4 박 번호 제거
- RANDOM RHYTHM 아래의 '16분 · 16분 ...' 텍스트 제거
- BPM 스와이프 안내 문구 제거 (스와이프 기능은 유지)
- 4/4 박자표를 오선 내부에 맞게 재배치
- 16분 grid를 그대로 그리는 대신 다음 onset까지의 간격을 이용해 더 간결한 음가로 표기
  - 1칸: 16분
  - 2칸: 8분
  - 3칸: 점8분
  - 4칸: 4분
- 무음 한 박은 4분쉼표
- 3연음 표기는 기존 방식 유지
- 오디오/랜덤/불빛/접이식 박별 설정/BPM 스와이프 기능 유지
