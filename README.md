# Randomtronome v8 — integrated score

v7의 악보 모양을 유지하면서 SCORE를 앱의 기존 카드/배경에 자연스럽게 통합했습니다.

- 흰색/아이보리 악보 종이 배경 제거
- 기존 Randomtronome 카드 배경 위에 오선보를 직접 표시
- 음표/쉼표: 밝은 회백색
- 오선: 부드러운 중간 회색
- 박 번호: 낮은 명도의 회색
- 4/4와 3연음 표기는 밝고 선명하게
- 기존 불빛 리듬 UI 유지
- PLAY/STOP, 즉시 정지, 랜덤 엔진은 기존 동작 유지

외부 음악 폰트/CDN 없이 SVG로 직접 렌더링합니다.
