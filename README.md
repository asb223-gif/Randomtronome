# Random Rhythm Metronome

4/4 한 마디를 랜덤 생성하고 반복 재생하는 브라우저 기반 리듬 트레이너입니다.

## 기능

- 16분음표만 / 16분음표 + 3연음 / 3연음만
- 혼합 모드의 3연음 출현 비율
- 40–240 BPM
- 일반 4분음표 클릭 ON/OFF
- 1~4박별 최소/최대 음 개수 설정
- 랜덤으로 생성된 리듬을 악보로 표시
- Play할 때 한 마디를 반복
- Stop 후 Play하면 새 리듬 생성
- Web Audio API로 디지털 클릭음 생성
- VexFlow 5.0.0으로 악보 렌더링

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. GitHub 저장소의 `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. `main` 브랜치 / `/ (root)`를 선택하고 저장합니다.
5. 잠시 후 GitHub Pages 주소가 생성됩니다.
